qadalign 0.1

Align plain-text lyrics to an audio file in the browser using a bespoke small ML model with 929K parameters. Your files and lyrics never leave your browser.

Make your lyrics match exactly what is sung in the audio file. Do not include any [Tags]. Every new line in the lyrics should correspond to a sung line in the audio file. The model is trained on English, so it may not work well for other languages.

Check out Vizzy for our free web-based music video editor that can use the output of this tool to create a lyrics video!
